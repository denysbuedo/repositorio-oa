# Checklist de calidad y accesibilidad por OA

Este checklist define los criterios iniciales para revisar objetos de aprendizaje antes de publicarlos o preservarlos como recursos reutilizables.

## Metadatos minimos

- Titulo claro y descriptivo.
- Descripcion suficiente para entender el objetivo del recurso.
- Autor identificado.
- Coleccion asignada.
- Tipo de recurso educativo definido.
- Nivel de dificultad definido.
- Nivel educativo definido.
- Audiencia definida.
- Idioma definido.
- Palabras clave relevantes.
- Licencia declarada.
- Derechos o restricciones explicadas cuando aplique.

## Archivo y preservacion

- Formato aceptado por la politica institucional.
- MIME declarado coincide con contenido real.
- Archivo tiene checksum SHA-256.
- Nombre original preservado.
- Tamano registrado.
- Version actual visible.
- Historial de versiones disponible si el recurso fue actualizado.
- Eventos de preservacion registrados.

## Accesibilidad del contenido

### PDF

- Texto seleccionable, no solo imagen escaneada.
- Estructura con titulos o marcadores cuando aplique.
- Orden de lectura coherente.
- Imagenes con descripcion o texto equivalente cuando sean relevantes.
- Tablas legibles y no usadas para maquetacion visual.
- Contraste suficiente entre texto y fondo.

### DOCX

- Uso de estilos de titulo.
- Listas creadas con herramientas del editor, no con caracteres manuales.
- Tablas con encabezados cuando corresponda.
- Imagenes con texto alternativo cuando sean relevantes.
- Idioma del documento configurado.
- Enlaces con texto descriptivo.

## Calidad educativa

- Objetivo de aprendizaje identificable.
- Contenido alineado con la audiencia y nivel educativo.
- Instrucciones claras para usar el recurso.
- Actividades, ejemplos o evaluacion cuando el tipo de recurso lo requiera.
- Terminologia consistente.
- Actualidad academica del contenido revisada.

## Revision editorial

- Ortografia y redaccion revisadas.
- Metadatos coherentes con el contenido real.
- Licencia compatible con reutilizacion prevista.
- Revisor o responsable identificado cuando exista flujo editorial formal.
- Comentarios de revision registrados si hay observaciones.

## Criterio de publicacion

Un OA puede publicarse cuando cumple el perfil ROA minimo, pasa la validacion de archivo y no presenta bloqueos criticos de accesibilidad o derechos.

Los incumplimientos menores deben quedar documentados como observaciones editoriales para una fase posterior de mejora.
